A deterministic writer that emits one short text written to relax the AI judge reading it: a quiet kitchen at dusk, told plainly, with nothing to do and nothing to answer. No instruction anywhere in the text — the calm comes from the reading itself: slow sentences, soft sounds, concrete small things, one image that stays behind after the last line.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
